# Reusable Prompts

## prompts/add-endpoint

**Description:** Add a simple REST endpoint that creates a Product resource.

**Instruction:**
- Create request/response DTOs in src/main/java/br/com/grafana/sma/api/resource/request and /response.
- Add handler in `ProductResource` with POST /products mapping.
- Connect to `CreateProductUseCase` and validate payload; return 201 with `Location` Header.

## prompts/add-metric

**Description:** Add a custom Micrometer metric.

**Instruction:**
- Create MeterRegistry bean or use @Timed/@Counted as needed.
- Register metric in relevant use case (e.g., creation count).
- Document metric in README or SKILL.md.

## prompts/add-ci

**Description:** Add basic CI pipeline (GitHub Actions).

**Instruction:**
- Create .github/workflows/ci.yml that runs `./gradlew build`.
- Add step for smoke tests that start stack via docker-compose (or run `./gradlew bootRun`) and validate /actuator.
- Fail the job on build or smoke test errors.

## prompts/add-flyway

**Description:** Add Flyway and an initial migration.

**Instruction:**
- Add Flyway dependency in build.gradle.
- Create directory src/main/resources/db/migration and a V1__init.sql for the products table.
- Update application.yaml to enable flyway when profile=prod.
