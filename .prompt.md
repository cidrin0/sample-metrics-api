prompts/add-endpoint:
  descrição: "Adicionar um endpoint REST simples que cria um recurso Produto."
  instrução: |
    - Criar DTOs de request/response em src/main/java/br/com/grafana/sma/api/resource/request e /response.
    - Adicionar handler no `ProductResource` com mapeamento POST /products.
    - Conectar ao `CreateProductUseCase` e validar payload; retornar 201 com Header `Location`.

prompts/add-metric:
  descrição: "Adicionar métrica customizada Micrometer."
  instrução: |
    - Criar bean MeterRegistry ou usar @Timed/@Counted conforme necessário.
    - Registrar métrica em usecase relevante (ex: contagem de criações).
    - Documentar métrica no README ou SKILL.md.

prompts/add-ci:
  descrição: "Adicionar pipeline CI básico (GitHub Actions)."
  instrução: |
    - Criar .github/workflows/ci.yml que execute `./gradlew build`.
    - Adicionar step de smoke tests que sobe stack via docker-compose (ou roda `./gradlew bootRun`) e valida /actuator.
    - Falhar o job em caso de erros de build ou smoke tests.

prompts/add-flyway:
  descrição: "Adicionar Flyway e um migration inicial."
  instrução: |
    - Adicionar dependência Flyway no build.gradle.
    - Criar diretório src/main/resources/db/migration e um V1__init.sql para a tabela products.
    - Atualizar application.yaml para habilitar flyway quando profile=prod.
