Como rodar localmente (dev)
1) Build:
   ./gradlew build

1.1) Rodar sem Docker (dev):
   ./gradlew bootRun

2) Usando Docker Compose:
   - Crie um arquivo .env baseado em .env.example
   - docker-compose up --build

Nota: o arquivo `.env.example` contém variáveis de exemplo. Nunca comite credenciais reais.

Verificações rápidas
- Acesse: http://localhost:8080/actuator
- Prometheus: http://localhost:9090
- Grafana: http://localhost:3000 (usuário/admin padrão no demo)

Dashboards provisionados: verifique os JSONs em `config/dashboards/` se alterar visualizações.

Checklist antes de PR
- Remover segredos, atualizar .env.example, rodar build e smoke tests.
- Incluir notas no README para mudanças na operação.
