# How to Run Locally (Dev)

## 1) Build

```bash
./gradlew build
```

### 1.1) Run Without Docker (Dev)

```bash
./gradlew bootRun
```

## 2) Using Docker Compose

- Create a `.env` file based on `.env.example`
- `docker-compose up --build`

**Note:** The `.env.example` file contains example variables. Never commit real credentials.

## Quick Checks

- Access: http://localhost:8080/actuator
- Prometheus: http://localhost:9090
- Grafana: http://localhost:3000 (default demo user/admin)

**Provisioned dashboards:** Check the JSONs in `config/dashboards/` if you modify visualizations.

## Checklist Before PR

- Remove secrets, update .env.example, run build and smoke tests.
- Include notes in README for changes in operation.

## Recommended Checks Before PR (Automatable)

- `./gradlew check` (includes linter/tests when configured)
- Run the team's formatter (IDEA/gradle) for consistency
- Run local smoke tests:
  - `curl -f http://localhost:8080/actuator/health`
  - `curl -f http://localhost:8080/actuator/prometheus`

## How to Report Issues

- Open an issue with the title `bug:` or `feature:` and include minimum steps to reproduce.
