Escopo de atuação
- Permitir: editar código fonte em src/main, criar/atualizar testes, ajustar build (build.gradle) para suportar mudanças.
- Proibir: commits com segredos, mudanças diretas em arquivos de CI sem revisão humana, alterações em /config/dashboards/* sem validação.

- Evitar mudanças large-scope em adapters (src/main/java/br/com/grafana/sma/adapter) sem testes de integração.

Regras operacionais
- Executar ./gradlew build e reportar erros antes de propor PR.
- Incluir uma descrição clara e testes de validação quando criar endpoints públicos.
- Para mudanças que alteram schema do BD, prefira adicionar migrations e marcar como breaking change.

- Se endpoints públicos mudarem, atualizar `OpenApiConfig.java` e gerar/validar a documentação OpenAPI.
