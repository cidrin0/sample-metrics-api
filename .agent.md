# Scope of Operation

## Allowed

- Edit source code in src/main, create/update tests, adjust build (build.gradle) to support changes.

## Prohibited

- Commits with secrets, direct changes to CI files without human review, alterations to /config/dashboards/* without validation.
- Avoid large-scope changes to adapters (src/main/java/br/com/grafana/sma/adapter) without integration tests.

## Operational Rules

- Run ./gradlew build and report errors before proposing PR.
- Include a clear description and validation tests when creating public endpoints.
- For changes that alter database schema, prefer adding migrations and mark as breaking change.
- If public endpoints change, update `OpenApiConfig.java` and generate/validate OpenAPI documentation.

## Recommended Automatic Checks

- Run formatter and linter (Checkstyle/SpotBugs) automatically.
- Run smoke tests in CI (curl /actuator endpoints) and fail the job if they don't pass.
- Validate OpenAPI when there are changes to controllers/resources.
